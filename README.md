# B站首页低质内容过滤

一个 Tampermonkey 用户脚本，用来清理 B 站首页推荐流：

- **低质内容**：短时长大字报、营销号、标题党、空洞抒情
- **指定话题**：13 类不想看的内容（两性对立、情感八卦、考公考研、车祸、搞笑段子、低俗、八卦、割韭菜、玄学、赌博、吃播、引战、土味）

设计目标是「**我来 B 站是获取知识的**」——宁可多拦一点，也不想被垃圾内容占领注意力。
误杀由白名单机制兜底，不是靠规则猜得更准。

## 安装

1. 装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox）
2. 打开下面的链接，点击「安装」：

```
https://raw.githubusercontent.com/wp2spc9mn8-sketch/bilibili_filter/main/bilibili-filter.user.js
```

装好后刷新 B 站，右下角出现徽章 `🛡 v4.2.0 aggressive 拦 N / 扫 M` 即生效。

脚本带 `@updateURL`，之后有新版本 Tampermonkey 会自动提示更新。

## 用法

**点右下角徽章** → 打开「最近拦截」面板：

- 逐条显示被拦了什么、属于哪类、为什么拦
- 拦错的点 **✅ 放行**，该 UP 主从此永不屏蔽，页面上已隐藏的卡片会立刻恢复

**卡片右上角悬停** → 出现 ⛔，点一下把这个 UP 主永久拉黑。

屏蔽的是**账号**，不是单条视频——这是对付「换一换又冒出来」的关键。

## 判定逻辑

两层，顺序是 **主题 → 质量**。

### 主题屏蔽

命中即拦，**完全不看时长和文案分数**——一条拍得再好的情感视频照样不要。

| 类别 | 拦什么 |
|---|---|
| `gender` | 性别引战、彩礼、凤凰男/扶弟魔、男女对立 |
| `relationship` | 出轨、恋爱脑、PUA、婆媳、异地恋、相亲市场 |
| `exam` | 考公、考研、事业编、押题班、保过班 |
| `accident` | 车祸、追尾、行车记录仪猎奇 |
| `comedy` | 沙雕、整活、鬼畜、段子、笑死体 |
| `vulgar` | 猎奇死亡、粪坑、擦边、偷拍、粗口 |
| `gossip` | 恋情曝光、塌房、红毯比美、黑料 |
| `hustle` | 副业月入过万、躺赚、0 基础变现、私域割韭菜 |
| `superstition` | 算命、风水、转运、塔罗、本命年 |
| `gambling` | 赌球、六合彩、百家乐、盘口 |
| `binge` | 大胃王、一口气吃 N 斤、生吃、催吐 |
| `flame` | 地域黑、网络对骂、粉丝互撕 |
| `lowbrow` | 社会摇、精神小伙、装疯卖傻、扮丑 |

每类规则分三级：

- **strong** — 命中即拦（词本身足够专指）
- **weak** — 需要同时命中 `weakNeed` 个才算（词有歧义，比如「分手」也可能是歌名）
- **exempt** — 命中则不拦（学术讨论、正经音乐、真运动项目）

这些**不该被拦**，规则里特意留了口子：

- `拳击基础教学` / `UFC 冠军赛` — 真运动，不是「打拳」
- `《分手快乐》现场版` — 歌名
- `搞笑诺贝尔奖` — 正经科普
- `交通事故责任认定标准解读` — 法规解读，不是猎奇
- `法医解读：尸检报告怎么看` — 医学内容
- `亚文化研究：土味视频为什么流行` — **在研究**，不是**在生产**

最后一条是这套规则的核心分野：讨论一个现象，和消费这个现象，是两回事。每条 `exempt` 都是在这个边界上手工校准的。

### 质量过滤

不按话题、只看内容本身的低质程度。用 `marketingFingerprint()` 打分：

**正分（低质特征）**

- 语义：营销词（震惊/盘点/揭秘/真相）、价格锚点、空洞升华（三观/格局/正能量）、
  引导互动（一键三连/点赞关注）、标题党标点、省略号堆叠、年份+长标题
- 结构：无栏目标记的长句、口语叙述、多短句、句末标点、标点密集

**负分（正常特征）**

- 栏目/系列标记：`【】`、`｜`、`#话题`、`MV`、`第N集`、`P3`、`《作品名》`
- 内容类型：攻略/实况/教程/讲解/评测/拆解/精讲/复盘/测评/开箱/合集/纪录片/花絮/混剪/手书/翻唱
- 英文专名（`Rust`/`Minecraft`/`RTX`…，通用缩写 `AI`/`NPC`/`MV` 除外）
- 知识词（生物/物理/数学/历史/音乐/摄影/算法…）
- 现象解释疑问句（「为什么…很少/越来越多/越来越贵」这类客观疑问）

**关键：结构分封顶 3 分，语义分不封顶。**

标题长度、逗号数量、句末标点、口语叙述是**同一个现象的多个侧面，不是独立证据**。
无上限累加会让正经科普拿到荒谬的高分：

> 「为什么超市里很少见到鹅肉？鹅非常好养，吃草就行，还能产鹅绒，但为什么越来越少了？」
> 结构分累加到 10 —— 而这是一条完全正常的科普。

封顶之后，这条的分数降到阈值以下，同时大字报召回没有下降。

另外：命中强营销词（盘点/震惊/揭秘/真相/内幕）时**知识保护失效**，
否则「盘点那些差点成功建造的反人类工程」会被「工程」两个字洗白。

### 阈值

```js
shortFpThreshold: 2   // 短于 120 秒
fpThreshold: 3        // 2–10 分钟
fpLongThreshold: 4    // 10 分钟以上
```

短视频**不按长度一刀切**——游戏片段、绘画、美食同样很短，砍长度会大面积误杀。
改用更低的指纹门槛。

### 优先级

```
已关注 → 用户白名单 → 用户黑名单 → 主题屏蔽 → 时长/文案规则
```

主题命中和黑名单算「硬拦截」，不会被 `keepAtLeast` 保底机制补回。

## 配置

改脚本顶部的 `CONFIG`，刷新页面生效：

```js
mode: 'aggressive',        // off | light | balanced | aggressive
keepAtLeast: 2,            // 每批保底保留条数，防止首页刷空
topics: {
  comedy: false,           // 单独关掉某一类
  // ...
},
showBadge: true,           // 右下角徽章
debug: false,              // 控制台打印每条判定
```

**觉得拦太多**：`mode` 改成 `'balanced'`，或关掉具体 `topics`。
**觉得拦太少**：三个 `fp` 阈值各减 1。

## 已知限制

- **接口层未生效**：hook `fetch`/`XHR` 在 B 站当前版本上从未触发，所有过滤都在页面层 DOM 完成。
  Tampermonkey 的 `@grant none` 跑在隔离环境，拿不到页面的 `window.fetch`。
- **标题完全干净的大字报会漏**：没有任何营销措辞、也没有口语特征时，文本规则抓不到。
- **误杀无法归零**：高召回的固有代价。用徽章面板的 ✅ 逐条放行。
- **只覆盖 Chrome**：Safari 需要先装 `Userscripts` 扩展。
- **擦边**只抓标题信号，封面擦边、标题正常的仍会漏。

## 安全设计

隐藏卡片时如果选到列表容器而非单张卡片，会把整个首页清空。实测踩过：
扫描 336 条、拦 51 条，页面全白。

三重保护：

- `MAX_LINKS_PER_CARD = 3`：一个卡片不该含超过 3 个视频链接，多了就是容器
- `findCard()` / `scan()` / `hideCard()` 逐层拒绝超标元素
- `recoverIfEmpty()`：每次全量扫描后检查，**如果一张可见卡片都没有，
  撤销所有隐藏并进入降级模式**（只记录、不再自动隐藏，徽章变红提示）

## 测试

```bash
node junk-test.js      # 营销号召回 / 误杀
node fp-test.js        # 大字报文案指纹
node mode-test.js      # 四档行为
node topic-test.js     # 13 类主题屏蔽
node dom-test.js       # DOM 层容器保护
node verify.js fixtures/rcmd-sample.json
```

当前结果：

- junk 召回 12/12、误杀 0
- fp 召回 6/6、误杀 0/17（另 1 条已知取舍）
- topic 召回 64/64、豁免误伤 0/53
- 240 条实时推荐：主题拦 7 条、质量拦 18 条，零误伤（命中率 10.4%）
